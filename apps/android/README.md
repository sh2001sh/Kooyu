# Kooyu Android

Kotlin + Jetpack Compose / Material 3 原生客户端，Android 8+（API 26），target/compile SDK 36、JDK 17。使用系统导航和深浅主题，宽屏显示导航侧轨，不嵌入 WebView。

Android Studio 打开本目录，或在安装 Android SDK 后执行：

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows 使用 gradlew.bat。Gradle 8.13 wrapper 的 JAR 与分发 SHA-256 已固定。APK 位于 app/build/outputs/apk/debug/，属于开发签名包。正式分发需自行配置签名，不将密钥或密码写入仓库。

图标以 `brand/icons/kooyu-app.svg` 为来源，在仓库根目录执行 `python scripts/generate-android-icons.py` 可重新生成（依赖 Pillow 和 CairoSVG）。兼容 PNG 保留 RGBA 透明通道；原生自适应图标分离珊瑚色背景、白色前景与单色层，Android 12+ 启动页使用同一自适应资源，避免透明圆角被填成黑色。

打开应用，填写友好的电脑名称，点击「扫描桌面二维码」，允许相机权限，对准桌面「设置 → 手机连接」生成的二维码；识别后点击「连接此电脑」。扫码确认、设备列表和切换菜单不显示连接 URL；手动输入在默认收起的高级入口。设备列表可添加、重命名、切换和移除多台电脑。整本设备凭据及各电脑未确认的操作使用 Android Keystore AES-GCM 加密，兼容旧版单电脑数据，备份关闭。拒绝明文 HTTP、跨地址重定向和非系统信任证书。

扫码使用应用内独立 Activity 和 ZXing Embedded 4.3.0，本机解码，不依赖外部扫码应用或 Google Play 服务，不上传或保存相机图片。相机权限按需申请，拒绝后可打开权限设置，无相机设备可手动输入；扫描页支持取消、补光、旋转和前后台释放/恢复相机。只接受有效 HTTPS Kooyu 邀请，不自动打开任意扫码网址。

扫码回归覆盖 Relay 路由保留、32 位十六进制邀请码、真实 QR 图像生成/解码及异常网址拒绝。实机相机、权限弹窗、旋转和切后台仍需要设备验收，构建通过不能代替这些行为证据。

0.2.0 提供会话、项目、待处理、用量、设置五个工作台入口，宽屏显示导航侧轨和会话分栏：

- 新建对话可选择项目、工作位置、引擎、会话类型、模型来源/绑定、模型、思考强度和权限，支持首条消息。首条发送失败保留草稿，避免重复创建。
- 会话支持标题/项目/归档过滤、置顶、重命名、归档和删除；全文历史搜索可定位消息。消息增量刷新，并可分页读取更早历史；原生 TextView 渲染 Markdown、代码、表格和链接。
- 支持发送、新回合、引擎声明的 steer、停止并暂停，待发消息可编辑、立即发送或撤回。文本附件最多 4 个，单个 64 KiB、合计 160 KiB，使用与桌面相同的消息格式。
- Claude、Codex、OpenCode、Kimi 的已知问答协议支持原生选择/多选/自由回答，以及协议允许的跳过或取消；保留原生审批语义，未知协议不猜测答案。
- 用量支持时间/项目/引擎/口径/会话筛选、Token 与缓存、实际/估算/未知费用、当地日期趋势、明细和项目预算。全局统计先剔除重复的会话累计快照，再执行日期筛选；未知费用不计为零。
- 项目和工作目录管理、文本文件预览、Git 变更与 diff；模型来源与端点、模型发现/编辑、引擎绑定/兼容检查、项目/电脑默认绑定、默认模型/权限、个人指令、外观与字号。
- 托管的观察/通知/自动继续、执行边界、暂停/撤销、控制权转交及项目授权。

前台会话每 2 秒刷新；用量每 10 秒刷新；进入后台均取消轮询。每次切换电脑清空工作台数据，并以电脑身份、token 与 generation 拒绝旧异步响应，避免会话和用量串到另一台电脑。各电脑的未知操作结果独立保存，先对账、不自动重发。

引擎安装/升级/登录、首次设置、系统入口修改和完整设备授权撤销仍在对应电脑本机操作。推送通知、图片/PDF 文件预览和任意未声明的交互协议不在本版中。完整功能及验证边界见 ../../docs/mobile-feature-parity.md。

CI 执行 Android 单测、lint 和 APK 构建；构建通过不能替代真实手机/TLS、系统回收与网络切换验收。
