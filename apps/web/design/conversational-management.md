# Conversational session management

Mode: Operate. A corrective extension of the existing workbench, preserving its current theme and form language.

THESIS: Ask Kooyu to manage work in the conversation instead of configuring supervision in a sidebar.

OWN-WORLD: Keep the incumbent quiet workbench and current interaction-card styles. No new palette, assets, or visual identity.

STORY: Name a session and desired action in Kooyu chat; tools resolve the target, show any required authorization in the conversation, and report actual receipts.

FIRST VIEWPORT: The session inspector contains overview, basic title/project actions, recovery and workspace information. It has no supervision, history-discovery or handoff form. Kooyu's composer indicates conversational management.

FORM: Reuse InteractionCard for readable action, target, destination, goal and limits, with allow/decline. Do not expose raw product-owned JSON or a structured-answer editor. Preserve native protocol interactions and direct stop controls.

BOUNDARIES: Native history and quota follow adapter support. A draft history read must not create a native session. New authority needs the actual user interaction answer; paused/stopped control cannot resume from a stale request. Handoff creates a linked conversation; it does not silently stop the source or claim delivery/completion.
