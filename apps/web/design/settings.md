# Settings surface

Mode: Operate. Scope: settings navigation, application preferences, engine installation and Provider configuration, model metadata and advanced mappings.

## Direction contract

THESIS: Make the engine-to-Provider-to-chat-model workflow understandable in one local settings surface.

OWN-WORLD: Preserve the implemented neutral split workbench, system typography, fine separators, restrained filled actions and status dots.

STORY: Add a Provider once, import models automatically, choose its engine route, and pick models in the conversation. Preserve native and saved routes.

FIRST VIEWPORT: Grouped settings navigation at left, a short explanation above a quiet engine list. Expand a row for installation and Provider fields, with the save action beneath them. Mobile uses section pills, stacked fields and existing bottom navigation.

FORM: Code-led expansion of the existing application. The signature interaction is progressive disclosure of one engine's installation, route and configuration history. Motion follows existing reduced-motion behavior.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
