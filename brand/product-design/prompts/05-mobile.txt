SURFACE: a polished MOBILE CLIENT APPLICATION SCREEN for Kodo, portrait 1024x1536. One complete front-facing mobile screen filling the canvas, with generous readable native-like UI scale. No several tiny phones in a landscape image, no hand holding a device, no physical phone frame or desk. This is a product UI design concept.

Reference image 1 provides the exact user-approved coral ribbon logo. Reference image 2 is the desktop workbench: carry over its warm-paper surfaces, coral action language, typography character and native-session semantics, adapted to one-column mobile use.

Design the selected conversation view. Small quiet status bar at top. Header: back chevron with "会话", title "梳理项目结构", secondary "Atlas · 示例项目". Small native-tool line "Codex · 原生会话". A simple overflow action. Beneath header a restrained status strip displays "设计示例" and "托管未开启"; it must not imply automatic delegation is always running.

Main content is a comfortable, generously spaced mobile chat transcript: user message "帮我梳理这个项目的入口和模块关系。"; assistant reply "我会先查看目录结构，再整理入口和依赖关系。"; one compact folded tool row "查看项目目录"; then a short clean module outline with small file icons, three example folders and a small text link "查看工作位置". Avoid many tiny illegible lines. Do not show invented test results, quotas or billing claims. The large central whitespace should feel calm and useful.

Bottom sticky composer: rounded warm-white input area with placeholder "继续这段工作…", attachment icon, small "Codex" context label and a coral send arrow with a large comfortable touch target. Immediately above or below, a clearly separated text action "停止并暂停托管". Bottom safe-area padding must be generous. A slim bottom navigation may have "会话", "待处理", "项目" only if it does not crowd the composer; the back navigation and conversation always stay clear.

This phone is a client for the same local host; do not imply execution on the phone, new remote cloud infrastructure, or continuation while the computer sleeps. A small explanatory footer can read "连接同一工作台". Keep the mock content labeled as design example.

Warm ivory #FAF8F4, white input surfaces, graphite text, deep-coral functional actions, subtle peach tints and small warm-gray separators. Beautifully readable Chinese typography, minimal line icons, friendly but precise 12-16px corners, high contrast and substantial touch targets. No enormous logo in the conversation, no decorative background ribbon, no blur/glass, no green or blue primary. The screen should feel like a thoughtful mobile extension of the desktop workbench.
