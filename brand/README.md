## 名称与品牌表达

Kooyu 是以此前 Kuyu 候选为灵感的品牌化拼写，不宣称是现成土耳其语单词。品牌表达为「让工作，接着向前」；品牌解释与词典原义分别记录。对外正文写 Kooyu，图形字标使用小写 kooyu。

正式域名尚未选定或注册。用户已了解有限同名筛查结果并确认使用此名称；这一确认不是商标清查结论。记录见 [命名筛查](naming-studies/kooyu/screening.json)。

## 软件与兼容

桌面窗口、托盘、网页标题、PWA、界面文案和产品主 agent 的自我介绍同步使用 Kooyu。为保持历史会话、凭据、配置与集成兼容，内部协议 ID、npm 包名、环境变量和已有数据目录保留旧键，不进行破坏性迁移。

正式文件使用 kooyu 前缀，旧 kodo 文件路径保留为兼容副本。独立图形与图标的视觉像素保持不变。
