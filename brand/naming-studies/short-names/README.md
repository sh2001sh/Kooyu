# 四字母名字复筛 · 2026-11-13

## 用户已明确的标准

- 保留 K 开头与现有丝带标志。
- 简洁好读，音感以 Kodo / Kool 为参照，优先四字母、两个音节。
- 名字有能讲清的词义来源；不为了拼出说明而拉长名称。
- 排查同类开发者工具与实际可用的网站地址。

本轮为研究候选，不代表用户已选定或产品已经更名；未更新正式资产与应用源码。

## 三个保留研究的方向

| 名字 | 建议读法 | 核验的字面来源 | 可发展的品牌解释（属于设计延伸） | 主观判断 |
| --- | --- | --- | --- | --- |
| Kuyu | koo-YOO / 库尤 | 土耳其语 kuyu，井 | 项目、工具与工作在一个地方汇聚；能力持续可用 | 当前域名组合较有空间，但英文读法需要一次引导 |
| Kumi | koo-mee / 库米 | 日语 組（くみ），组合、成组的事物或一起做事的群体 | 不同工具各有身份，在一个项目里协作 | 音感亲和、语义贴切，常用域名占用较多 |
| Koti | ko-tee / 科蒂 | 芬兰语 koti，家、住所 | 给项目和会话一个工作归处 | 安静、温暖，常用域名占用较多 |

上述品牌解释不是词典原义，不宣称这些词原本就表示 AI、编程或工作台。

## 域名实际查询

使用 IANA 官方 RDAP bootstrap 确定注册局查询端点，逐个检查。机器记录与 UTC 时间见 [domain-screening.json](domain-screening.json)。

截至 2026-11-13 本次查询：

- `kuyu.com`、`koti.com`、`kumi.com` 均返回注册记录。
- `kuyu.app`、`kuyu.dev`、`getkuyu.com`、`usekuyu.com` 均返回 HTTP 404，没有返回注册记录。
- `koti.app`、`koti.dev`、`kumi.app`、`kumi.dev`、`getkoti.com`、`usekoti.com`、`getkumi.com` 均返回注册记录。

404 不等于注册商最终可注册性或价格保证；未进行购买或预订，也未完成商标与近似名称清查。

## 有限公开检索的观察

对 Kuyu 进行了名称加 software/app、AI assistant、coding agent、developer tools 等组合的有限网页检索；返回结果中存在开发者姓氏与文章作者账号，未据此识别出明确同名的编程工作台。不能将有限检索结果视为没有其他使用者或法律可用性结论。

决策上，先保证名字音感与直接同类产品的辨识度，再在短品牌名与网站地址之间做取舍；不要求品牌名必须等于裸 `.com`。普通跨行业同名与直接同类产品应分别分析。当前最值得优先继续核查的是 Kuyu；Kumi / Koti 保留作音感、语义对照。
