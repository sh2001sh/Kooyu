# 原生会话同步与本地删除回归

日期：2026-11-13。本轮覆盖全部 11 个已注册 harness；保留工作区其他功能及品牌调整。

## 同步语义

- Host 启动后检查，随后每 60 秒检查；有原生 ID 的会话可以从右键菜单手动同步状态。
- 原生状态区分 present、missing 和 unknown。只有能够确认原生历史缺失时，才允许清理本地记录。
- 自动清理要求曾存在原生历史或已有发送证据，并且至少两次缺失检查相隔 5 秒；空白会话不会因尚未生成日志而被自动删除。
- 原生归档历史仍算存在。暂不可读、权限不足、列表不完整、格式损坏、服务失败均不作为删除证据。
- 运行中、连接建立中、有在途命令的活动连接受保护；原生已删除的空闲连接可以安全关闭并清理本地记录。
- 删除确认与 harness、workspace/目录、binding/revision、原生存储环境关联。切换这些条件或扫描中发生变更后，旧检查不能证明新环境中的缺失。
- 自动扫描按批次轮转；显式删除按指定会话检查，移除项目检查全部成员，不受自动扫描 200 条上限影响。
- 删除及归档菜单管理的是本地记录；本地删除不删除原生历史或项目文件。原生归档不会被误判为删除，但不保证将各厂商的归档标记双向映射到本地。

## 各适配器检查依据

| Harness          | 检查依据与保守边界                                                                              |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| Codex            | 完整分页读取活跃及归档列表，再精确读取 ID；列表不完整或通信异常不能证明缺失                     |
| Claude Code      | 扫描原生 projects 下的精确 UUID 日志，覆盖不同工作树；不单凭 SDK 列表缺项清理                   |
| pi / Kodo        | 映射日志和原生 ID 头检查；兼容同 ID 日志改名；恢复时拒绝缺失或无效日志，防止重新创建            |
| Gemini           | 核验项目映射和原生日志元数据；旧格式、损坏或不可读记录保留 unknown                              |
| Kimi Code        | 合并完整活跃及归档列表；达到条数上限、命令失败或损坏响应保留 unknown                            |
| Cursor           | ACP 列表提供存在证据；明确不支持列表时使用精确本地元数据，普通列表缺项不能证明删除              |
| Grok Build       | ACP 存在证据及明确不支持时的原生本地摘要回退；不完整来源不证明缺失                              |
| OpenCode         | 精确查询 session ID，404 才视为缺失；归档仍存在，其他 HTTP 错误保留 unknown；检查后关闭隔离服务 |
| ZCode            | 精确 reconcile 返回的 ID、workspace 和存在/删除字段；遗漏或格式异常保留 unknown                 |
| DeepSeek Harness | 检查原生持久化会话各代日志及压缩日志；未知布局或自定义 profile 不能证明缺失                     |
