# 定时任务简化实现与验收（2026-11-16）

已补齐 Kooyu 主对话创建定时任务的确认流程，并将桌面/Web、Android、iOS 的常用时间配置改为选择器。用户不需要填写 cron、授权 ID 或资源字符串。

## 使用方式

- 在 Kooyu 主对话里说“每天上午 9 点检查项目”“每周一、周三下午 3 点汇总进度”“每隔 90 分钟检查一次”。Kooyu 根据工作内容和时间调用计划工具；缺少必要时间、时区信息时澄清。
- 创建、修改时在对话中确认任务名称、工作内容、时间、时区、执行电脑、状态与限制。用户接受后才保存任务并创建必要的执行授权，拒绝不产生任务或授权。
- 对话支持列出、查看、修改、暂停及立即运行；工作记录与成果 → 自动计划可查看列表、编辑、预览接下来执行时间、启用或暂停、查看运行记录。桌面工作中心 → 计划也支持直接新建；首次使用通过明确的允许按钮授权，无需手写配置。
- 常用频率：只执行一次、每天、周一至周五、每周多天、每月指定日期、每隔一段时间。间隔支持分钟、小时、天。Android 使用原生日期、时间弹窗，iOS 使用 DatePicker，桌面使用日期／时间输入控件。
- 时区和次数／费用限制放进可展开设置。旧的复杂 cron 和外部事件保留为高级选项；常见旧 cron 自动显示为时间选择项。
- 最大继续次数、最大连续失败、费用上限默认显示 0，表示不限制；计划的运行次数和费用上限同样支持 0。负数、非整数次数及非有限费用仍拒绝。原有正数限制继续有效，独立配置的项目预算继续生效。
- 托管截止时间使用开关与原生日期／时间选择器，关闭开关则没有截止时间。Web 日期、时间和授权到期时间点击或键盘打开选择器，阻止直接键入、粘贴日期文本；选中后由控件生成标准格式。
- 产品连接文案统一为“设备”。设备管理与切换菜单将“添加设备”放在列表上方；旧版自动生成的“电脑 N”“我的电脑”兼容显示为设备名称，其他自定义名称保留。

## 行为与边界

日历计划按保存的 IANA 时区执行。每月不存在的日期跳过；夏令时不存在的重复计划时刻跳过，重复时刻只执行较早的一次。单次计划必须是未来的真实日期和时间；夏令时中不存在的单次时刻拒绝保存。

固定间隔以持久化 startAt 为锚点，不受时区和夏令时影响。“天”表示 24 小时；新建或修改间隔后等待一个间隔，未改变间隔的编辑保留原锚点。漏过多次时沿用已有 skip／coalesce 策略，不因重启或延迟扫描产生逐次补跑或时间漂移。

普通聊天保留计划；停止主对话或接管正在执行／等待执行的计划会暂停未来触发。暂停保留已有运行记录，当前已执行工作沿用既有停止语义。桌面工作中心编辑暂停任务保留其状态；工作台和移动端“保存并启用”明确启用任务。

计划和执行授权保存在 Host，共享给同一 Host 的已配对客户端。任务绑定所属主对话，通过对话列出的是该主对话自己的任务。远程客户端不能调用本机授权接口提权；它可以在用户发起的主对话中接受审批。自动化回合不能自行创建新计划。请求重放、并发重复、修改版本和停止期间的审批均受检查。

计划依赖 Host 和指定执行电脑在线。离线设备恢复时按保存的错过时间策略处理，不是 Android 本地闹钟。

## 主要实现

- 协议增加 calendar 和 interval，保留 once／cron／webhook；共享编辑值转换和自然语言描述。
- Host 增加日历／固定间隔计算、无授权预览、对话确认后保存和授权、并发与持久请求去重。
- Kooyu 提示词及 automation 工具直接接入对话创建和管理。
- 三端复用已有品牌和计划管理入口，简化常用字段，折叠高级字段；审批卡片直接展示任务明细。
