# 首次启动引导

## 目标与范围

让新用户按需配置主 Agent API、准备需要的原生 Harness，再进入工作台。API 为可选项，既能跳过这一项继续准备引擎，也能跳过整个引导直接开始。沿用工作台的纸面、珊瑚色品牌标识和原生表单，不用轮播介绍代替实际设置。

桌面采用左侧三步清单、右侧任务面板；手机采用顶部紧凑进度和纵向表单。主 Agent 负责理解和委派，Harness 负责执行；独立 Harness 的登录不等于主 Agent 的 API。

## 三步流程

1. **连接主 Agent（可选）**：填写来源名称、接口格式、Base URL 和密钥，保存并获取模型列表，再选择主模型。可以跳过本步直接准备 Harness，也可跳过整个引导进入工作台。支持复用已保存来源、重试、手动添加模型及补齐能力参数。复用系统凭据库和默认绑定接口。模型列表可读取不等于真实对话通过；不自动发送付费测试消息。
2. **准备执行引擎**：自动检测已有安装，优先展示常用引擎，可以展开全部。托管安装复用 EngineManager，其他引擎链接原生安装说明。展示安装中、失败和重试。已安装只表示程序可启动，登录仍需用户完成。不强迫下载全部引擎，也不要求先配置主 API，不将主 API 自动覆盖到各引擎。
3. **开始使用**：回顾主模型、已安装引擎及账号边界，进入主对话或打开引擎设置。不自动发消息，不创建示例工程。

## 状态与恢复

- 状态存在本机 Host 的 SQLite，不依靠浏览器 localStorage 判定首次启动，不保存密钥或表单正文。
- 首次读取固定本轮状态；有会话、项目、Provider、应用偏好或绑定的旧安装自动视为已有用户。
- 步骤完成后保存检查点，关窗后恢复。未提交密钥关闭后需重填。
- 顶部始终可以稍后设置，保留已保存配置；设置 → 通用可以重开。完成后不自动弹出。
- 请求失败可重试，不视作已完成。远程配对客户端不弹电脑端引导。
- revision 防止多窗口覆盖，不自动重发安装、创建来源或保存绑定。

## 验收

覆盖全新 Host、旧数据迁移、跳过重开、状态持久化、失效修订、无 API 完成引导；桌面/手机覆盖 API 保存与模型绑定、发现失败、手动参数、安装状态、重载和无溢出。自动测试的模型目录不代表真实推理和各家登录通过。
