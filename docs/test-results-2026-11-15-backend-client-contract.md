# 后端跨端接口补齐：实现与验证记录

日期：2026-11-15。测试对象为当前工作区，含先前已有的未提交变更，不能视为某个干净发布提交的认证。本轮只修改后端、共享协议、测试及文档，没有修改客户端界面。

## 交付内容

1. 能力接口保留旧标志，增加身份权限、可用状态、阻塞原因和上传/同步限制。未知操作默认不支持。
2. 本机管理员可对单设备显式授予或撤回 goals.check，带授权修订冲突检查；实际检查路由执行同一约束，设备撤销清除委派。
3. 新 Goal 聚合详情串联会话、工作区、成果、验证、历史和待处理项。按全部关联成果 ID 读取，明确区分缺记录、缺内容和可用文件。
4. 通知业务上下文解析保留原目标，不因目标缺失跳向另一任务；读取不修改已读、审批或验收状态。
5. 管理写操作有持久化幂等回执、并发去重、设备隔离、参数冲突检查及重启恢复。同步数据与确认同事务提交；未知副作用不重放。
6. 权限目录与参数校验共用，新增会话配置解析，区分已有会话固定绑定、原生观察值和新会话默认配置。
7. 新原生同步支持集合增删改、顺序、复合键、游标重置和有界缓存，旧全量快照保持兼容。
8. 文件内容增加 HEAD、单段 Range、ETag、If-Range、If-None-Match，继续认证、流式读取和内容安全限制。通知分页拒绝非整数和非有限值。

## 修复过程中发现的问题

- Store.addProject 原来直接 BEGIN/COMMIT，不能组合进管理回执外层事务；改为复用 Store.transaction，并验证失败回滚与提交后回执一致。
- 通用成果列表存在 500 条限制，不能直接用于完整 Goal 聚合；改按 Goal 保存的关联 ID 读取。
- 原生 current=null 是合法观察结果，不能用空值合并运算符替换成会话旧配置；新增 observed 并保留原生 null。
- Host 重启后不能把未知管理写操作当作普通失败重试；通过持久回执及进程身份识别阻止重放。

- 没有重新构建 Android APK 或运行 iOS，也没有把前一轮截图冒充本轮后端测试证据；前一轮 93 张桌面、38 张 Android 截图仅用于前端问题分析。
- 未做真实模型调用、真实厂商登录、APNs 真机端到端、Android 系统回收/弱网/锁屏、生产升级或正式签名发布验收。
- 同步采用内存有界快照缓存，重启后全量重置，不宣称持久化离线复制。管理 unknown 仍需核对业务对象，不自动对账。
- Range 是单段，不支持 multipart；对象同长度外部篡改未在每次下载时重新哈希。
- 客户端尚未接入新增接口；本轮后端通过不等于移动端已有目标验收、完整文件资料和工作中心入口。
