# Kooyu 品牌规范

正式名称 Kooyu；字标 kooyu；读音 KOO-yoo。品牌定义以 [identity.json](../brand/identity.json) 为准，素材见 [brand/assets](../brand/assets/README.md)。

图形继续采用 A「灵动回环」莫比乌斯丝带；不得改变比例、重新描摹成僵硬的标准 K，或使用绿色作为主色调。

| 角色 | 色值 |
| --- | --- |
| 日落珊瑚 | #F17561 |
| 桃色高光 | #FFD0B3 |
| 深莓折面 | #A03259 |
| 暖纸画布 | #FAF8F4 |
| 深墨文字 | #28232A |
| 操作强调 | #BE4C42 |

字标使用 Quicksand 590、轻微前倾和光学字距；交付 SVG 全部转为路径。颜色与字体参数见 [设计变量](../brand/assets/tokens.json)。

名称以 Kuyu 为灵感作品牌化拼写，不把 Kooyu 宣称为现成土耳其语词。品牌主张：让工作，接着向前。正式域名未选定或注册。

独立图形建议至少 24 px，横版组合建议至少 120 px，四周保留约图形高度 1/6 的空白。深色背景使用对应反白字标，不拉伸、不额外加描边。手机托盘和 favicon 优先用独立图形。

软件对外显示 Kooyu；内部旧 ID、凭据服务名、历史数据目录与环境变量保留兼容。旧文件路径是兼容副本，取用新文件优先 kooyu 前缀。六张原始生图仍为 Kodo 历史稿，正式字标以最新 SVG 为准。
