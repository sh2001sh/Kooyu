# 移除旧配置入口与绑定迁移

日期：2026-11-12。此记录只覆盖当前未上线仓库的配置收敛；此前真实 harness 对话结果见 [Provider 验收](test-results-2026-11-12-providers.md)。

## 实现范围

- 唯一配置路径为 Provider → 模型库 → Harness 绑定。新会话和默认值直接引用绑定 ID/修订；Host 从固定 Provider 修订生成隔离运行配置。
- 旧配置 API、编辑入口及新建路径已移除。SQLite v5 映射能确定关系的旧镜像 ID，清理旧记录，并保留旧会话的原生 ID、命令与事件历史。
- 旧会话的运行配置无法安全恢复时，Host 拒绝重新连接，桌面和手机共用的输入组件禁用发送并提示新建会话。旧历史仍可查看。
- 系统凭据库清理保留当前 Provider 与会话固定修订仍引用的密钥。
