# 工作中心简化与子代理页面修复

日期：2026-11-17

## 工作中心

- 新建计划不再因没有主对话而无解释地禁用。点击后可选择项目、创建 Kooyu 主对话，再继续设置计划；创建本身不发送消息或执行任务。
- 计划表单直接提供“允许此主对话按计划自动执行”，保存时仅创建当前主对话的 `automation.execute` 授权。先验证计划；保存临时失败后重试复用已有授权。预览不会创建授权。
- 应用连接说明连接账号与授予操作范围的区别；常用授权可勾选中文操作名称。自定义应用、OAuth 与 Webhook 配置按需展开。
- 项目记忆可独立选择项目，无需先创建主对话。日常只需填写约定内容；标题可自动生成，手动来源自动记录，额外来源可选。
- 执行环境明确默认在本机运行。独立浏览器、远程电脑配置默认收起；远程工作目录改用表单选择电脑、项目、文件夹路径。
- 通知独立于主对话选择。桌面通知无需地址；仅选择 Bark 时显示必填的推送地址；说明 APNs 属于自部署 iOS 服务配置。

## 子代理

- 修复标签数量或标题长度撑宽对话区域的问题，对工作区与内层 flex 元素设置明确的收缩和溢出约束。
- 标签支持横向滚动、滚轮滚动、前后按钮、关闭、收起；“全部子代理”可定位任意代理并重新打开标签。关闭标签不会调用停止、删除或其他写接口。
- 主对话与子代理分别保留阅读位置。主对话隐藏期间的实时更新不应触发滚动跟随或搜索定位。
- 修复子代理接口的 500：数据库查询排除只有状态通知、没有嵌套事件的记录，分页游标只计算真实对话事件。
- 将对应 Agent 调用的失败工具回执显示为失败，成功回执显示完成；普通内部工具失败不会把整个子代理误判为失败。
- 旧持久化活动投影通过版本号重建，无需编辑原始日志。

## 真实错误的归属

生产数据确认：Agent 原生工具回执为 `InputValidationError`，参数未能解析为 JSON；此前 Kooyu 仍将同一条目显示为 running。另一个 `AskUserQuestion.multiSelect` 报错表示工具收到数组，预期布尔值。参数错误来自模型/供应商原生调用链；Kooyu 的状态、页面读取与布局错误已分别修复。未修改工具参数来猜测或替代用户意图。
